# 质量验收清单

每个阶段完成后必须对照检查，不合格返回上一阶段修正。

## 6.1 剧本验收

- [ ] 开篇3秒有钩子，能留住人
- [ ] 核心冲突清晰，主角目标明确
- [ ] 每集结尾有断钩子，引导下一集
- [ ] 角色动机合理，不是工具人
- [ ] 反派有具体恶行，惩罚到位
- [ ] 角色清单8列填写完整
- [ ] 场景清单和道具清单齐全
- [ ] 台词符合人物身份，千人千面
- [ ] 情绪爽感有具体落点，不是空喊口号
- [ ] 没有AI难生成的大规模场景（千人战争、连环车祸等）

## 6.2 分镜验收

- [ ] 镜头节奏匹配情绪（紧张=快切，抒情=慢推）
- [ ] 动作连续有因果，不跳步
- [ ] 景别变化有层次，不是全是中景
- [ ] 台词长度匹配镜头时长
- [ ] 转场方式明确，不是硬切到底
- [ ] POV镜头遵守7条规则
- [ ] 运镜方式合理，一个镜头不堆叠多种运镜
- [ ] 情绪全部外化，没有"很悲伤""很愤怒"等直述
- [ ] 动作描写有部位+幅度+速度+力度
- [ ] 命名全程一致，不中途换称呼
- [ ] 道具位置状态跨镜头连续
- [ ] 时间逻辑连续（白天不会突然变黑夜）

## 6.3 资产验收

### 角色资产
- [ ] 角色三视图+脸部特写齐全
- [ ] 三视图与脸部特写100%一致
- [ ] 正面脸正对镜头，五官对称
- [ ] 服装发型饰品三视角统一
- [ ] 纯白背景
- [ ] 16:9横版版式正确

### 场景资产
- [ ] 场景六视图齐全（全景/中景/左/右/特写/反向）
- [ ] 空间结构六视图统一
- [ ] 物理锚点清晰，跨视角能对上
- [ ] 主光源方向色温统一
- [ ] 纯场景没有人物
- [ ] 16:9横版

### 通用
- [ ] 命名规范，便于后续引用
- [ ] 角色之间有视觉差异化，不会撞脸
- [ ] 场景有叙事性细节，不是空房间
- [ ] 美学描述用专业词，不用"高级""好看"

## 6.4 关键帧验收

- [ ] 每集7张关键帧齐全（1START + 6END）
- [ ] 全部使用I2I生成，引用了资产图
- [ ] 角色外观服装发型一致
- [ ] 道具位置状态连续
- [ ] 场景光影时间逻辑对
- [ ] 首帧尾帧情绪有变化弧线
- [ ] 编号与segment对应正确
- [ ] 构图符合横竖屏规则
- [ ] 没有人物崩坏、穿模

## 6.5 视频验收

### 画面质量
- [ ] 画面稳定不闪烁
- [ ] 人物面部不崩坏
- [ ] 动作自然不僵硬
- [ ] 没有多手指、肢体扭曲
- [ ] 没有水印、字幕、乱码文字
- [ ] 颜色正常不过曝不偏色

### 连续性
- [ ] 角色外观跨镜头一致
- [ ] 道具位置状态连续
- [ ] 场景空间不漂移
- [ ] 光影时间逻辑统一

### 声音
- [ ] 台词口型基本同步
- [ ] 声音层次清晰，不糊
- [ ] 音乐音效台词比例合适
- [ ] 没有杂音、电流声

### 节奏
- [ ] 镜头节奏符合分镜设计
- [ ] 情绪弧线完整
- [ ] 结尾断钩子到位
